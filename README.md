# GA16-24 Homebrew tap

Litescape shows your Litematica selections and schematic placements in 3D while you build in Minecraft. This tap installs its desktop app, which opens the viewer in its own window instead of a browser tab.

```sh
brew install --cask GA16-24/tap/litescape
```

It works on macOS and Linux. Windows users can download the installer (`Litescape-<version>-win-x64.exe`) from [Releases](https://github.com/GA16-24/homebrew-tap/releases).

The app needs Minecraft running with the Litescape mod. Until the game starts, it shows "Waiting for Minecraft".

The cask and releases here are published automatically. Please don't edit them by hand.
